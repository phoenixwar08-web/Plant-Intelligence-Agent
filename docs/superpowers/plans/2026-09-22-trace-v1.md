# Trace V1 Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with tests first. Steps use checkbox syntax for tracking.

**Goal:** Build a local `trace.v1` Store that correlates existing Shadow records and sourced model metrics without becoming a decision or execution input.

**Architecture:** Add an isolated `services/soil3/trace/` package. One Store-generated trace ID maps to one atomic JSON record. The Store exposes only creation, named decision-field set-once updates, append-only Feedback references, one-time Outcome attachment, and deep-copy reads.

**Tech Stack:** Python standard library, repository JSON persistence helpers, unittest, JSON Schema.

**Spec:** `docs/superpowers/specs/2026-09-22-trace-v1-design.md`

## Global Constraints

- Store association metadata and observed metrics only; never embed upstream business objects.
- Do not infer facts, calculate reward/token/cost/latency, call a model, or make a decision.
- Decision fields are set-once; Feedback references append only; Outcome changes from null once.
- Create execution exactly as `phase3_called=false` and `physical_actions_performed=false`; never expose an execution update.
- Do not import or call Phase3, MQTT, ActuatorLayer, `manual_water`, or pump code.
- Do not modify #21 runtime integration; it is the later producer of this contract.

def set_decision(self, trace_id: str, **updates: Any) -> dict[str, Any]:
    if not updates or set(updates) - DECISION_FIELDS:
        raise TraceError("validation_failed", reasons)
    record = self._load(trace_id)
    candidate = copy.deepcopy(record)
    for field, value in updates.items():
        _validate_decision_field(field, value)
        _apply_set_once(candidate["decision"], field, value)
    candidate["updated_at"] = utc_now()
    self._write(candidate)
    return copy.deepcopy(candidate)
```

Validate every proposed field before writing. The initial empty value is the sole unset state; identical retries do not alter the record and differing values raise `TraceError`. Metric values require their fixed real source (`provider_response.usage`, `provider_response.billing`, or `runtime_monotonic_clock`), a finite non-negative value, and the metric's fixed unit. No generic patch API is added.

def append_feedback_refs(self, trace_id: str, refs: list[dict[str, Any]]) -> dict[str, Any]:
    record = self._load(trace_id)
    values = _validated_new_feedback_refs(refs, record["feedback_refs"])
    candidate = copy.deepcopy(record)
    candidate["feedback_refs"].extend(copy.deepcopy(values))
    candidate["updated_at"] = utc_now()
    self._write(candidate)
    return copy.deepcopy(candidate)

def set_outcome_ref(self, trace_id: str, ref: dict[str, Any]) -> dict[str, Any]:
    _validate_reference(ref)
    record = self._load(trace_id)
    candidate = copy.deepcopy(record)
    _apply_set_once(candidate, "outcome_ref", ref)
    candidate["updated_at"] = utc_now()
    self._write(candidate)
    return copy.deepcopy(candidate)
```

No removal, replacement, reordering, or bulk patch method is permitted.
