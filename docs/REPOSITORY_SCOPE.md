# 仓库范围

## 计划纳入

- 可公开且可追溯的服务源码：数据接入、Phase1、Phase3、handoff、只读 Web；
- Plant Agent 的状态、推理、分析、事件和测试代码；
- OpenClaw 的白名单工具、规则和无密模板；
- ESP32 固件源码、构建说明、设备 manifest 与安全测试记录；
- 数据库 schema、迁移定义、脱敏样例和数据集 manifest；
- 实验代码、实验配置、指标和模型卡；
- 部署示例、依赖锁定、测试和回放脚本。

## 明确排除

- 生产数据库、原始 MQTT、传感器数据、日志、CSV、spool 与运行 JSON；
- 密钥、Token、密码、真实连接串、私有网络信息、Wi-Fi/Broker 凭据；
- OpenClaw memory、state、sessions、media、聊天记录与账号配置；
- Python/Node 虚拟环境、缓存、编译产物、`.bak*` 和未审查历史副本；
- 模型权重与固件二进制，除非另有授权、来源、许可与 hash 策略；
- 未经验证的硬件规格、设备安全能力或物理执行结论。

## 目录角色

| 目录 | 角色 | 是否可直接获得泵发布权限 |
| --- | --- | --- |
| `services/` | 可部署数据接入与控制服务 | 仅未来明确的 Actuator Interface 可拥有 |
| `agents/` | 状态、推理、工具、记忆与交互适配 | 否 |
| `modules/` | 领域模型、配置契约、日志与公共接口 | 否 |
| `experiments/` | 训练、评估、基线和研究结果 | 否 |
| `web/` | 展示与受限请求界面 | 否 |
| `firmware/` | 设备端源码及构建证据 | 设备消费命令，但须有最后安全边界 |

在任何生产 import 前，本范围文件与 `manifest/` 是批准依据。
