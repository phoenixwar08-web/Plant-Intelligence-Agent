# Phase 1 完成标准

Phase 1 只完成“新仓库可开始受控导入”的前提，不完成任何业务迁移。

- [x] 独立仓库定位与来源说明；
- [x] README、仓库范围、目标架构、导入政策与忽略规则；
- [x] 生产基线索引与资产清单模板；
- [x] 明确工程、Agent、实验、数据、固件和运行状态边界；
- [x] 固件、Broker、设备回执等未解决安全项已登记；
- [ ] 目标 GitHub remote 连通性与初始推送确认；
- [ ] 每个未来导入模块的完整生产来源 manifest；
- [ ] 用户逐模块确认首个 production import 的范围。

进入导入前，必须同时满足最后三项；否则仓库仅是治理与规划基线。
