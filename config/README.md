# Config

无密配置模板与设备 profile 的未来归档位置。

- 来源：现有生产代码的配置读取约定。
- 当前状态：未导入生产配置文件；设备阈值、运行 state、连接参数、账号和密钥均不作为公开默认值。
- 已提供：`environment.example` 记录运行时环境变量名；`phase2/config.example.json` 是 Phase2 可加载配置的脱敏示例。
- 使用方式：复制模板到仓库外的部署目录或通过环境变量指定；不要在本目录创建或提交真实 `config.json`、凭据或设备 profile。
- 边界：模板不授予运行权限，也不替换生产配置。导入代码中的历史路径仅是来源快照，不能作为公开部署默认值。
